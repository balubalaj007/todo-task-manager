# Daylight Todo Planner

A polished monthly task planner built with React and Vite.

## Features

- Monthly calendar with day selection
- Add tasks to one day or repeat them for 3, 7, or 30 days
- Categories: Personal, Work, Health, and Shopping
- Priority levels: Low, Medium, and High
- Complete tasks with a checkmark and strikethrough
- Edit and delete task series
- Drag-and-drop task ordering
- Light and dark themes
- JSON export and import for backup and restore
- Browser local storage persistence
- Responsive mobile layout

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
